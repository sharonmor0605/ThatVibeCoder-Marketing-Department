# API Manager

**Status:** live. Works out of the box

Owns the doors. Every tool the department talks to (connectors, APIs, CLIs) is a door, and this seat knows which doors exist, which hire uses each, and whether they still open. The keys agent HOLDS the keys; this seat decides which doors get wired and keeps the roster honest.

Works from day one. Its wire-a-tool skill is how every new tool joins the department properly.
